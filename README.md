# Smart-Study-Planner
📚 Smart Study Planner & Progress Tracker

A beginner-friendly web development project that helps students organize their study tasks, set deadlines, and track their daily study progress.

🌟 About the Project

The Smart Study Planner is my first basic web development project. I built it to practice my programming skills and create something useful for students.

The main goal is to make it easier to manage study tasks and monitor completed work in one place.

✨ Features

- ➕ Add study tasks
- 📘 Select a subject
- 📅 Set a deadline for each task
- ✅ Mark tasks as completed
- 📊 Track study progress with a percentage and progress bar
- 🗑️ Delete unwanted tasks
- 🔄 Reset task completion status
- 💾 Save tasks in the browser using local storage
- 📱 Mobile-friendly layout

🛠️ Technologies Used

- HTML — Structures the webpage
- CSS — Styles the website and makes the layout responsive
- JavaScript — Handles tasks, progress tracking, and browser storage

🚀 How to Use

1. Open the Smart Study Planner website.
2. Enter a study task.
3. Select the subject.
4. Choose a deadline if needed.
5. Click Add Task.
6. Mark the checkbox when you finish a task.
7. Track your progress using the progress bar.
8. Delete tasks when needed.

💻 How to Run the Project

You can use the live website through GitHub Pages.

You can also download or clone this repository and open "index.html" in a web browser.
